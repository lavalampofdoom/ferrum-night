# Ferrum Night

Free browser zombie survival set on real Franklin County, Virginia pavement — Ferrum College, 180 Ferrum Mountain Road, VA-40, Fairy Stone Park Road, and Rocky Mount.

**Play:** [https://lavalampofdoom.github.io/ferrum-night/](https://lavalampofdoom.github.io/ferrum-night/)

Search the [field guide](https://lavalampofdoom.github.io/ferrum-night/guide) for places, loot, guns, and wildlife. No install. Works on any computer with a browser.

Houses open into small rooms. Ferrum College opens into halls, classrooms, and dorms. A bat drops a walker in two to four hits; rare brutes drop you in two. Guns are loot. A sow and two cubs roam the western woods — do not touch them.

## Controls

- WASD walk · Shift sprint
- E search / enter / sleep / claim
- Space attack
- I pack and craft

## Local

```bash
npm install
npm run dev
```
