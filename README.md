# Ferrum Night

Free browser zombie survival set on real Franklin County, Virginia pavement — Ferrum College, 180 Ferrum Mountain Road, VA-40, and Rocky Mount.

**Play:** [https://lavalampofdoom.github.io/ferrum-night/](https://lavalampofdoom.github.io/ferrum-night/)

Search the [field guide](https://lavalampofdoom.github.io/ferrum-night/guide) for places, loot, guns, and wildlife. No install. Works on any computer with a browser.

Houses open into halls and rooms. Search crates instead of vacuuming them. A bat has to land close. Aim with the mouse. You cannot see through walls.

## Controls

- WASD walk · Shift sprint · mouse aim
- E search / enter / pick up
- Space strike (toward the mouse)
- I pack · drop items from the pack
- Cars: E enter · W/S drive · A/D steer

## Local

```bash
npm install
npm run dev
```
