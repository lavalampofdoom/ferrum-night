# Ferrum Night

Free browser zombie survival set on real Franklin County, Virginia pavement — Ferrum College, 180 Ferrum Mountain Road, VA-40, Fairy Stone Park Road, and Rocky Mount.

**Play:** [https://lavalampofdoom.github.io/ferrum-night/](https://lavalampofdoom.github.io/ferrum-night/)

Search the [field guide](https://lavalampofdoom.github.io/ferrum-night/guide) for places, loot, guns, cars, and wildlife. No install. Works on any computer with a browser.

Houses open into rooms with beds, shelves, and crates. Some doors start locked — bash them, then lock from the inside. Walkers slip in through unlocked doors faster if the door is gone. The clinic on Ferrum Mountain Road keeps the only standing crafting table; craft more and place them. Cars hold about two minutes of gas. You cannot be bitten while driving. Ram them.

## Controls

- WASD walk · Shift sprint
- E search / enter / lock / car
- Space strike
- I pack and craft
- In a car: W/S drive · A/D steer · E exit

## Local

```bash
npm install
npm run dev
```
